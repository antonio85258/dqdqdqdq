# Практическая работа №1.3 — Server и Client Components

Готовый проект по заданию: структура Next.js App Router, Server/Client Components, `use client`, `use server`, статические и динамические маршруты, `generateStaticParams` и пример товара.

## Запуск

```bash
npm install
npm run dev
```

Откройте http://localhost:3000

## Маршруты

- `/server-demo`
- `/client-demo`
- `/greet-demo`
- `/about`
- `/blog/nextjs-vvedenie`
- `/blog/react-osnovy`
- `/products/1`
- `/products/2`

Проект рассчитан на Next.js 15 и Node.js 18.17+ (рекомендуется LTS).
